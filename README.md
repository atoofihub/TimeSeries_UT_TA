# TimeSeries_UT_TA

درس‌نامهٔ فارسی **تحلیل سری زمانی دانشگاه تهران** برای دانشجویان کارشناسی ارشد ژئودزی.

استاد: دکتر سعید فرزانه · دستیار آموزشی: علیرضا عطوفی

## مشاهدهٔ درس‌نامه

پوشهٔ مخزن را کامل دریافت کنید و `index.html` را در مرورگر باز کنید. این نسخه شامل مقدمه، ۲۴ درس و یک پیوست است. فونت‌ها، لوگوها، موتور نمایش فرمول و دادهٔ نمودار همگی محلی‌اند؛ مشاهدهٔ صفحات به اینترنت، CDN، سرور، بک‌اند یا نصب کتابخانه نیاز ندارد.

در GitHub از **Code → Download ZIP** استفاده و فایل را از حالت فشرده خارج کنید؛ سپس `index.html` را باز کنید. دریافت تک‌فایل HTML برای نمایش کامل کافی نیست، زیرا پوشهٔ `assets` نیز لازم است.

برای دریافت با گیت:

```sh
git clone https://github.com/atoofihub/TimeSeries_UT_TA.git
cd TimeSeries_UT_TA
```

## ترتیب مطالب

۱. مبانی جبر ماتریسی، مدل تصادفی و کمترین مربعات.
۲. شش حالت سرشکنی و برآورد، هر کدام در یک صفحهٔ مستقل با روابط و مثال عددی.
۳. برآورد مؤلفه‌های واریانس و کمترین مربعات دسته‌ای و بازگشتی.
۴. سیستم‌های دینامیکی خطی، انتقال وضعیت، مدل حرکت و نویز.
۵. پیش‌بینی، فیلترینگ و هموارسازی، استخراج کالمن و مثال عددی.
۶. کاربرد در سری زمانی موقعیت، پیاده‌سازی و ارزیابی آماری.
۷. پرسش‌های مرور و پیوست روابط و اصطلاحات.

فهرست درس‌ها، جست‌وجوی عنوان‌ها، فهرست مطالب هر صفحه و پیوندهای قبلی و بعدی، مسیر مطالعه را مشخص می‌کنند. صورت تمرین اول و فایل‌های داده از بخش «صورت تمرین و داده‌ها» در صفحهٔ اصلی قابل دریافت‌اند.

## ساختار فایل‌ها

```text
index.html                   صفحهٔ اصلی و فایل‌های تمرین
lessons/                     صفحات کامل آمادهٔ مشاهده
content/course.json          ترتیب و مشخصات درس‌ها
content/lessons/              متن قابل ویرایش هر درس
assets/                      فونت، لوگو، قالب، فرمول و نمودار
assets/mission-01/           صورت تمرین و داده‌های دانشجویی
scripts/build.py             تولید صفحات
scripts/check.py             کنترل ساختار و پیوندهای آفلاین
scripts/check_examples.py    کنترل عددی شش حالت سرشکنی
scripts/check_publication.py کنترل محتوای قابل انتشار
```

## ویرایش و افزودن درس

متن درس را در `content/lessons/` و مشخصات آن را در `content/course.json` ویرایش کنید. فایل منبع هر درس یک `h2` برای عنوان و `h3` برای زیرعنوان‌ها دارد. سازنده، عنوان اصلی و فهرست کناری را تولید می‌کند.

از ریشهٔ مخزن اجرا کنید؛ Python نسخهٔ ۳٫۹ یا جدیدتر کافی است و این بررسی‌ها به کتابخانهٔ اضافی نیاز ندارند:

```sh
python3 scripts/build.py
python3 scripts/check.py
python3 scripts/check_examples.py
python3 scripts/check_publication.py
```

برای درس جدید، فایل منبع و یک مدخل با شناسهٔ یکتا، نام فایل، عنوان، توضیح و `phase` معتبر در آرایهٔ `lessons` اضافه کنید. فایل‌های `lessons/` خروجی تولیدشده‌اند و با اجرای سازنده بازنویسی می‌شوند. برای حفظ امکان مشاهدهٔ مستقیم، تغییر منابع و خروجی HTML را با هم ثبت کنید.

روابط باید همراه تعریف نمادها، فرض‌ها و واحدها باشند. مثال عددی باید دادهٔ ورودی، جایگذاری در روابط و نتیجهٔ قابل بررسی داشته باشد. کدهای Python داخل درس، برای اجرای مستقل ممکن است به NumPy نیاز داشته باشند؛ نمایش HTML به آن‌ها وابسته نیست.

## قالب و دارایی‌ها

قالب از مجموعهٔ `GPS_UT_TA` پیروی می‌کند: لوگوهای دانشگاه تهران و دانشکدهٔ فنی، فونت محلی IRANSans، زمینهٔ خاکستری و صفحهٔ سفید با تأکیدهای آبی. حقوق محتوا، نشان‌ها و فونت‌های مبدأ محفوظ است. MathJax تحت Apache-2.0 عرضه می‌شود و اعلان‌های آن حفظ شده‌اند.

صورت تمرین و دو CSV دانشجویی بدون تغییر در `assets/mission-01` قرار دارند. نمودار تعاملی از ۱۳۷۷ نمونهٔ گرد‌شدهٔ موقعیت استفاده می‌کند؛ برای محاسبات پروژه، CSV کامل به کار رود. ده نمونهٔ آغازین نمودار برای مقداردهی اولیه مصرف می‌شوند و دوباره در اصلاح وارد نمی‌شوند.
