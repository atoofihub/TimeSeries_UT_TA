# دارایی‌های محلی

- فایل‌های `ut_logo.png` و `fanni_logo.png` و خانوادهٔ `fonts/IRANSansWeb*` از پوشهٔ `assets` ریپوی محلی `GPS_UT_TA` کپی شده‌اند.
- فایل `vendor/mathjax-tex-svg.js` عیناً از اسکریپت تعبیه‌شدهٔ HTML ورودی استخراج شده است. فونت‌های ریاضی در خروجی SVG قرار می‌گیرند. بارگذاری خودکار افزونه‌های TeX و منوی افزونه‌های آنلاین در `math-config.js` غیرفعال شده‌اند تا نمایش فرمول به CDN نیاز نداشته باشد.
- فایل `route-data.js` همان ۱۳۷۷ نمونهٔ نمودار موجود در HTML ورودی را نگه می‌دارد؛ شامل زمان نسبی، شرق، شمال و شاخص دقت. این فایل، جایگزین بستهٔ کامل دادهٔ پروژه نیست.
- فایل `route-demo.js` نمایش تعاملی فیلتر سرعت ثابت را با خواندن دادهٔ محلی و مقداردهی اولیه از ۱۰ اپک آغازین اجرا می‌کند.
- فایل `lesson-content.css` سبک بلوک‌های آموزشی ورودی را نگه می‌دارد. قالب مرجع GPS و اصلاحات خوانایی در `style.css` اعمال می‌شوند.

هیچ نیازی به کتابخانه‌های استفاده‌نشدهٔ GPS مانند Bootstrap، Mermaid، Chart.js یا KaTeX وجود ندارد؛ فقط دارایی‌های مورد استفاده منتقل شده‌اند.

بستهٔ `mission-01` از پوشهٔ دانشجویی تمرین اول کپی شده و شامل PDF صورت تمرین، `observations.csv` و `can_optional.csv` است. مرجع دقیق‌تر در آن وجود ندارد. نمودار مسیر برای جلوگیری از شمارش دوبارهٔ داده، ۱۰ نمونهٔ نخست را فقط در مقداردهی اولیه مصرف می‌کند.
